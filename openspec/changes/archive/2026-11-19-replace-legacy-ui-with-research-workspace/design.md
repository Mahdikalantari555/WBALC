## Decisions

- Retain the existing SvelteKit visual identity. Applying Impeccable's Operate guidance, put intake in a dedicated workspace view, keep a clear next action after each write, and keep research downloads beside sampling history. Use native labeled controls and inline recovery, with English/Persian and logical spacing.
- Upload multipart streams on the server; the browser does not see the engine URL or token. The engine validates file content, schema, and size. The Node adapter allows 520 MiB per multipart request to cover the default 512 MiB file limit and envelope.
- A sampling round is a durable query batch, not a training iteration. Distinguish the number selected, number currently marked labeled, and number of retained first label versions created by that batch. Re-labels and manual/imported labels are not counted as new queried samples. Existing hard deletion prevents reconstructing deleted label versions; the export explicitly discloses that limit.
- JSON v1 includes project metadata, input metadata, batches and query-time values, retained label versions, run metrics and immutable manifests. CSV uses one row per item, plus a summary row for empty rounds. The CSV also has numeric pixel and map centre columns with a CRS column. Both preserve native CRS and pixel positions without inferring coordinates or prediction values. These are provenance exports, not bundles of raster or checkpoint binaries.
